# 左手OLED交換用4連LEDステータスモジュール

専用ブランチ: `feature/polaris-oled-led4`。LEDは左手に4個だけ取り付けます。
通常OLED版は維持します。右手は従来のファームを使用し、BLE経由で電池残量を通知します。
左LPPS/TB/JOY/ENCの `_LED4` ファームを用意しています。
交換時は必ず電源を切ってください。

## 表示フロー

1. 起動／idle復帰から2秒: 1〜4に色相差を付けた虹色グラデーション。緩やかにフェードインして色が流れます。
2. 次の2秒: 1→2→3→4を2周。右手接続済みは青、未接続は赤。PCとの接続状態ではありません。
3. 以降はidleまで: 1・2で左の電池、3・4で右の電池を表示。各ペアは同じ色です。

残量80〜100%は明るい青、30〜79%は緑、0〜29%は赤。
未取得・右手未接続は白でゆっくり明滅し、0%と区別します。
右手の切断で保存残量を無効化し、再接続後に新しい通知を受けるまで未取得表示です。
電池表示中に接続が変化したら、接続シーケンスから再表示します。
USB給電でも電池でも同じフローです。

30秒無操作でidleになったらアニメーションを停止してLED電源を遮断します。
操作再開で虹色から再実行します。通常の連続打鍵ではフローを再スタートしません。
残量は既存のNiMH電圧換算による推定値であり、正確な容量計測ではありません。

## 配線

| OLED端子 | LEDモジュール | XIAO |
| --- | --- | --- |
| SDA | 先頭DIN | D9 / P1.14 |
| SCL | LED_EN（LowでON） | D10 / P1.15 |
| VCC / GND | 電源 / GND | 既存端子 |

左TPDはDR信号がP1.14なので併用禁止（snippetを両方選ぶとエラー）。
LED用SPI3はデータのみ使用し、TB用SPI0とは分離。
LED版ではOLED／I2C1を無効化します。XIAO内蔵RGBは変更しません。
animationとext-power-transientはEquinoxと同じ固定SHA。
独自ステータスアニメーションはこのリポジトリ内でのみ追加し、依存リポジトリを変更しません。
キー配置は変更していません。LED版で `&animctl ANM_DS` ／ `&animctl ANM_EN` を
割り当てれば手動OFF／ONも可能です。表示モードはこのフロー1種類です。

生成DTS／設定検査と、色の閾値・左右割当・時系列境界・未取得表示のCテストを含む4テスト成功。

実機未検証: GRB順序、ゲート極性、LEDの並び方向、消灯時の消費電流、
右手の残量取得・切断・再接続、idle復帰、入力との同時動作。
